The missing layer

Delegation is easy. Knowing what actually happened is harder.

A model name in a prompt is not proof of routing. A finished chat is not proof of task acceptance. A timeout is not useful if the child process keeps running.

Codex Factory wraps the existing Codex CLI with a narrow operating contract: preview the exact route, persist the reservation, own one worker process, and retain a terminal receipt. The coordinator still makes the decisions.

Controls you can inspect

The factory floor is intentionally small.

Version 0.1.1 focuses on the supervision and qualified-routing boundary that can be proven today.

01

Qualify, then route

Test every worker-capable candidate against exact role harnesses, then pin the selected provider, model, sandbox, repository, and prompt.

02

Admit deliberately

Dry-run first. Recheck the aggregate budget under a single-worker lock, then persist the reservation before launch.

03

Own the process

Supervise the exact child tree. Timeout and interrupt handling must reap it—or retain the lock as a stop condition.

04

Separate facts

process_completed means the CLI produced a terminal artifact. It never masquerades as acceptance.

One bounded shift

From task contract to evidence.

  1. 1

    Write the contract

    Unique ID, user-visible outcome, acceptance criteria, allowed paths, and runnable checks.

  2. 2

    Preview the route

    Inspect the model, provider, reasoning, sandbox, reservation, timeout, and exact command.

  3. 3

    Execute once

    The runner locks admission, records the reservation, starts one child, and never retries automatically.

  4. 4

    Verify independently

    Read the final artifact and run the task checks. Integrate only the evidence-supported result.

Evidence, not theater

Keep the artifacts that let a coordinator disagree with the worker.

Every run retains the exact request, JSONL events, stderr diagnostics, final message, terminal result, and aggregate usage record. Raw receipts stay local and ignored by Git because they may contain repository data.

Release status

Useful for controlled experiments. Not yet an autonomous factory.

Version 0.1.1 is an evidence-producing prototype. It discovers candidates, binds qualifications to exact runtime fingerprints and roles, selects qualified capacity, and supervises one worker at a time.

Included now

  • One supervised worker
  • OpenAI and Ollama routes
  • Persistent reservations
  • Process-tree cleanup
  • Machine-readable receipts

Not in 0.1.1

  • Hard in-turn token cutoff
  • Parallel scheduling
  • Campaign dependency graph
  • Automatic acceptance or merge
  • PM-facing control room
Important budget boundary

Codex exposes usage after a turn. The runner can refuse admission and reject an over-budget result, but it cannot stop a single turn at an exact token count.
